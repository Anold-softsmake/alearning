A programm

1.3 Encapsulation and Data Hiding
Encapsulation bundles data and the methods that operate on that data inside a class. Data hiding restricts direct 
access to internal state, commonly by declaring fields private and
exposing controlled methods.
class BankAccount {
private double balance;
public void deposit(double amount) {
if (amount > 0) {
balance += amount;
}
}
public double getBalance() {
return balance;
}
}
1.4 Abstraction
Abstraction exposes essential operations while hiding unnecessary implementation details.
abstract class Shape {
abstract double area();
}
class Circle extends Shape {
private double radius;
Circle(double radius) {
this.radius = radius;
}
@Override
double area() {
return Math.PI * radius * radius;
}
}
